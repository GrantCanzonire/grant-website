# Grant Canzonire - Personal Portfolio

## Project Overview
This website is my personal portfolio created for ISDS 3100: Information Systems Foundations. It presents my background as an Information Systems & Analytics student, my skills and experience, and my interest in cybersecurity.

## Website Structure
- index.html - Main portfolio page with profile, skills, experience, and contact information
- resume.html - Expanded resume page
- project.html - Projects page
- styles.css - Styling and responsive design for the website

## Deployment
The website is deployed publicly using GitHub Pages.

## Reflection
While working with the AI coding agent, I learned that version control gives me more control over AI-generated changes. When an AI-generated change altered my Projects page in a way I did not want, I used Git to restore only project.html from an earlier commit instead of undoing the entire website. This showed me how Git can be used to recover specific files while keeping other improvements.
